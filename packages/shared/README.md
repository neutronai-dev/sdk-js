# @neutron-ai/shared

Shared TypeScript API types for Neutron AI SDKs and connectors.

This package is published as ESM with generated declaration files and is intended to be consumed by `@neutron-ai/sdk` and platform integrations.

```sh
npm install @neutron-ai/shared
```

New integrations should use `nucleusId`. `tenantId` remains a compatibility alias and must match when both fields are supplied.
