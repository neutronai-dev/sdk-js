# Neutron AI JavaScript and TypeScript SDK

The TypeScript SDK, CLI and shared contracts for [Neutron AI](https://neutronai.dev): scoped memory, knowledge, context and consequence workflows for AI agents.

| Package | npm | Source |
|---|---|---|
| SDK | [`@neutron-ai/sdk`](https://www.npmjs.com/package/@neutron-ai/sdk) | [packages/sdk-ts](packages/sdk-ts) |
| CLI | [`@neutron-ai/cli`](https://www.npmjs.com/package/@neutron-ai/cli) | [packages/cli](packages/cli) |
| Shared contracts | [`@neutron-ai/shared`](https://www.npmjs.com/package/@neutron-ai/shared) | [packages/shared](packages/shared) |

```sh
npm install @neutron-ai/sdk
```

Documentation: [neutronai.dev/docs](https://neutronai.dev/docs). Licensed under [Apache-2.0](packages/sdk-ts/LICENSE).
